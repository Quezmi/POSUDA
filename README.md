# ООО «Посуда» — Информационная система для магазина посуды

## Описание проекта
Проект представляет собой информационную систему для магазина **ООО «Посуда»**, специализирующегося на продаже посуды и кухонных аксессуаров. Система предназначена для установки на терминалах в торговых центрах, а также для работы с авторизованными пользователями через веб-интерфейс.  

Цель проекта — упростить процесс просмотра товаров, формирования заказов и управления ассортиментом.

---

## Функциональные возможности

### Для клиентов:
- Просмотр ассортимента товаров.
- Фильтрация и поиск по категориям и характеристикам.
- Формирование и редактирование заказов (для авторизованных клиентов).
- Выбор удобного пункта выдачи.

### Для менеджеров:
- Авторизованный доступ.
- Просмотр и редактирование заказов клиентов.

### Для администраторов:
- Управление товарами: добавление, редактирование, удаление.
- Контроль за актуальностью информации о товарах.

### Для терминалов (неавторизованные и авторизованные пользователи):
- Просмотр товаров и их характеристик.
- Формирование заказов.
- Выбор пункта выдачи заказа.
